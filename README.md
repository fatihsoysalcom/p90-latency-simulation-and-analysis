# P90 Latency Simulation and Analysis

This Python script simulates MCP connection wait times to demonstrate how a P90 latency of 35 seconds can occur. It highlights the difference between average and P90 metrics by generating a distribution with a few outliers.

## Language

`python`

## How to Run

Run this script using Python: `python p90_latency_sim.py`
